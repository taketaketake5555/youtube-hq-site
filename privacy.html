Privacy Policy

youtube-hq · Last updated: 22 November 2026

youtube-hq is a private tool operated by one person for their own YouTube channels. It has no other users. This policy describes how it handles data obtained through Google and YouTube API Services.

Data it accesses

  • YouTube Data API (read-only): public channel and video information for the operator's channels, such as titles, view counts, subscriber counts and publish dates. It also runs public video searches.
  • YouTube Analytics and Reporting APIs (read-only): the operator's own channel reports, such as views, watch time, average view percentage and subscriber changes.

It does not access any other Google account data, and it does not access data belonging to anyone other than the operator.

How the data is used

The data is used only to produce a daily report for the operator. It is not used for advertising, and it is not sold.

Where the data is stored and who receives it

  • Daily statistics and reports are stored in a private repository and on the operator's own computer.
  • Aggregated statistics are sent to an AI text service to write a short summary, and the finished summary is delivered to the operator through a messaging service. These providers process the data only to perform those tasks.
  • The data is not shared with any other third party.

Retention and deletion

Stored statistics are kept for as long as the operator finds them useful and can be deleted by the operator at any time. Access tokens are kept as encrypted secrets and are removed when access is revoked.

Revoking access

Access can be revoked at any time from the Google Account permissions page: https://myaccount.google.com/permissions.

YouTube API Services

youtube-hq uses YouTube API Services. By using it, the operator agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Contact

Questions about this policy can be raised by opening an issue on the repository that hosts this page.
